## Что реализовано

Одностраничный лендинг по эталонному макету:

1. **Верхняя полоса** — «Мы всегда рады помочь по телефону» + номер и кнопка «Заказать звонок» (модальное окно).
2. **Шапка** — логотип и меню из 7 разделов: преимущества, о нас, особенности, каталог, команда, бренды, полезное.
3. **Главный экран** — фото на всю ширину, затемнение, заголовок My-Giro, подзаголовок, кнопка «к каталогу».
4. **Преимущества** — слайдер со стрелками: 2 слайда по 4 преимущества, переключение на CSS.
5. **О нас** — текст о магазине.
6. **Подписка** — оранжевая полоса: имя, e-mail, кнопка «Подписаться».
7. **Особенности гироскутеров** — три колонки: минусы, плюсы, плюсы; итоговый абзац.
8. **Каталог** — фильтр по виду и 9 карточек: бейдж вида, фото, название, цена.
9. **Консультанты** — 3 карточки: фото, имя, должность, кнопка «Написать».
10. **Бренды** — Xiaomi, Smart Balance, Linbol, Kugoo, Subor, Airwheel.
11. **Полезная информация** — 4 статьи с подписью поверх фото.
12. **Подвал** — о компании, три колонки ссылок, копирайт. Плюс кнопка «наверх», закреплённая снизу экрана.

## Соответствие требованиям задания

| Требование | Как выполнено |
|---|---|
| Слайдер преимуществ переключается | радиокнопки + `:checked` в CSS, стрелки ‹ › |
| Фильтр товаров без перезагрузки | `:checked ~ .catalog__grid` скрывает лишние карточки |
| Работает без языков программирования | в проекте нет ни строки JavaScript |
| Кнопка «наверх» всегда снизу экрана | `position: fixed` |
| Анимации | `@keyframes`, плавные переходы, уважение `prefers-reduced-motion` |
| Адаптивность, в том числе планшет 1024×1366 | медиазапросы 1100 / 1024 / 860 / 600 px |
| Валидные HTML и CSS | семантическая разметка, без ошибок |
| Структурированный и комментированный код | CSS разбит на 18 пронумерованных блоков |
| Логотип в векторе | `assets/logo.svg` |

## Технологии

- HTML5 (семантика: `header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3: переменные, flexbox, grid, `:checked`, `:target`, анимации, медиазапросы
- Шрифт Open Sans (Google Fonts) с системным fallback
- Без сборки и без зависимостей: достаточно открыть `index.html`
